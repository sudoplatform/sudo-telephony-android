AvailablePhoneNumber

data class AvailablePhoneNumber(val phoneNumber: String, val countryCode: String, val numberType: PhoneNumberType, val locality: String? = null, val region: String? = null) : Parcelable

A phone number the telephony service is offering to provision.

The carrier does not reserve an offered number, so it can be taken by someone else before it is provisioned.
