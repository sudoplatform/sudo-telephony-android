PhoneMessageEvent

data class PhoneMessageEvent(val id: String, val phoneNumberId: String, val conversationId: String, val type: PhoneMessageType, val direction: PhoneMessageDirection, val changeType: PhoneMessageChangeType, val seen: Boolean, val owner: String, val version: Int, val updatedAt: Date) : Parcelable

Notification that one of the caller's phone messages was received, updated or deleted.

The event carries no message content, only the change and enough identity to act on it. Fetch the message with com.sudoplatform.sudotelephony.SudoTelephonyClient.getPhoneMessage to read its text.
