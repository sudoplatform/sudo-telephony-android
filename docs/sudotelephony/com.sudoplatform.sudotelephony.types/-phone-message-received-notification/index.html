PhoneMessageReceivedNotification

data class PhoneMessageReceivedNotification(val messageId: String, val owner: String, val sudoId: String?, val phoneNumberId: String, val conversationId: String, val remotePhoneNumber: String, val bodyPreview: String, val bodyTruncated: Boolean, val mediaOmitted: Boolean, val receivedAt: Date) : Parcelable

A push notification that a message was received on one of the user's phone numbers.

The notification carries a preview of the body. Fetch the full message with com.sudoplatform.sudotelephony.SudoTelephonyClient.getPhoneMessage using messageId.
