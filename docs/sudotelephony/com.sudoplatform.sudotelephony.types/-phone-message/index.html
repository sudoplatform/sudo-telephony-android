PhoneMessage

data class PhoneMessage(val id: String, val owner: String, val owners: List<Owner>, val phoneNumberId: String, val conversationId: String, val type: PhoneMessageType, val direction: PhoneMessageDirection, val localPhoneNumber: String, val remotePhoneNumber: String? = null, val body: String, val segmentCount: Int, val mediaOmitted: Boolean, val seen: Boolean, val receivedAt: Date, val version: Int, val createdAt: Date, val updatedAt: Date) : Parcelable

A message sent to or from one of the caller's phone numbers.

The other party's number and the message text are sealed in transit and unsealed by the SDK with the private key held on this device, so reading a message requires the device that provisioned the number.
