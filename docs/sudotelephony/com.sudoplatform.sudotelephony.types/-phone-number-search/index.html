PhoneNumberSearch

data class PhoneNumberSearch(val id: String, val countryCode: String, val areaCode: String? = null, val results: List<AvailablePhoneNumber>, val expiresAt: Date, val owner: String, val version: Int, val createdAt: Date, val updatedAt: Date) : Parcelable

The result of a search for available phone numbers.

The service keeps the search so that provisioning can check the requested number came from it. Pass id as the search id when provisioning one of the results.
