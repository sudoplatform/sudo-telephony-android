PhoneNumber

data class PhoneNumber(val id: String, val owner: String, val owners: List<Owner>, val identityId: String, val keyRingId: String, val keyIds: List<String>, val phoneNumber: String, val countryCode: String, val numberType: PhoneNumberType, val areaCode: String? = null, val state: PhoneNumberState, val failureReason: PhoneNumberFailureReason? = null, val gracePeriodEndsAt: Date? = null, val clientRefId: String? = null, val version: Int, val createdAt: Date, val updatedAt: Date) : Parcelable

A phone number provisioned for a user.

Provisioning returns the number in PhoneNumberState.PROVISIONING; it becomes PhoneNumberState.ACTIVE or PhoneNumberState.FAILED once the order completes with the telephony provider.
