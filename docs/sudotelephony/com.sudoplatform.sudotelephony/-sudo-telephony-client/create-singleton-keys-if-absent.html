createSingletonKeysIfAbsent

abstract suspend fun createSingletonKeysIfAbsent(): CreateSingletonKeysIfAbsentResult

Create the singleton key pair every phone number is sealed to, if this device does not have it.

Requires a client built with Builder.setEnforceSingletonKeyPair. Call it once the user is signed in, before provisioning: provisioning never creates the key, and fails with PhoneNumberException.SingletonKeyPairNotFoundException without it.

The result says whether the key had to be created. If it was, the device's key material has changed, so back the keys up again with exportKeys. If the user already has phone numbers, a new key also means this device does not have the one they are sealed to (for example a second device, or one whose keys were removed), so import the user's key backup with importKeys.

Return

Whether the singleton key pair was created, and its identifier.

Throws

SudoTelephonyClient.CryptographicKeysException.InvalidConfigurationException

if the client does not enforce a singleton key pair; otherwise CryptographicKeysException if the key cannot be created.
