deprovisionPhoneNumber

abstract suspend fun deprovisionPhoneNumber(id: String): PhoneNumber

Release one of the caller's phone numbers.

The unit of the caller's phone number allowance is returned at once and the number is handed back to the telephony provider in the background. Releasing a number that is already released returns it unchanged, so the call is safe to repeat.

Only an com.sudoplatform.sudotelephony.types.PhoneNumberState.Active or com.sudoplatform.sudotelephony.types.PhoneNumberState.Suspended number can be released; releasing one that is still being provisioned fails with PhoneNumberException.InvalidPhoneNumberStateException.

Return

The PhoneNumber in com.sudoplatform.sudotelephony.types.PhoneNumberState.Released.

Parameters

id

String ID of the phone number to release. Unless the client enforces a singleton key pair, the number's key pair is then removed from the device. If that fails, this throws PhoneNumberException.KeyPairRemovalFailedException, which carries the released number.

Throws

SudoTelephonyClient.PhoneNumberException

if the number could not be released, or PhoneNumberException.KeyPairRemovalFailedException if it was released but its key pair could not be removed.
