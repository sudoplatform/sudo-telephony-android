importKeys

abstract suspend fun importKeys(archiveData: ByteArray)

Replace the cryptographic keys held on this device with those in archiveData.

A phone number's messages can only be unsealed with the private key generated when the number was provisioned, so importing an archive exported from another device is how a number's messages become readable there.

Every key already on this device is removed first, so the store ends up matching the archive rather than merging with it.

Parameters

archiveData

ByteArray The key archive to import, as returned by exportKeys.

Throws

SudoTelephonyClient.CryptographicKeysException

if the archive is empty or cannot be read.
