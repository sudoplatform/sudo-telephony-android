SudoTelephonyClient

interface SudoTelephonyClient : AutoCloseable

Interface encapsulating a library for interacting with the Sudo Platform Telephony service.

Operations are grouped by domain; all service calls are suspend and return public types. Construct instances through the Builder; the concrete implementation is internal.
