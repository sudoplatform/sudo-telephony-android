listPhoneNumbersForSudoId

abstract suspend fun listPhoneNumbersForSudoId(input: ListPhoneNumbersForSudoIdInput): ListOutput<PhoneNumber>

Retrieve a page of the caller's phone numbers that one Sudo owns, oldest first.

Lists the same states as listPhoneNumbers. A Sudo that has no numbers, or that belongs to another user, reads as an empty page.

Return

A ListOutput holding this page of numbers and the token for the next one.

Parameters

input

ListPhoneNumbersForSudoIdInput The Sudo and paging parameters.

Throws

SudoTelephonyClient.PhoneNumberException

if the numbers could not be retrieved, or if the Sudo ID is empty (PhoneNumberException.InvalidArgumentException).
