listPhoneNumbers

abstract suspend fun listPhoneNumbers(input: ListPhoneNumbersInput = ListPhoneNumbersInput()): ListOutput<PhoneNumber>

Retrieve a page of the caller's phone numbers, oldest first.

Lists numbers that are being provisioned, active or suspended. Released and failed numbers are not included; fetch those by id with getPhoneNumber.

Return

A ListOutput holding this page of numbers and the token for the next one.

Parameters

input

ListPhoneNumbersInput Paging parameters.

Throws

SudoTelephonyClient.PhoneNumberException

if the numbers could not be retrieved.
