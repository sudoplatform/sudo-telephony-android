provisionPhoneNumber

abstract suspend fun provisionPhoneNumber(input: ProvisionPhoneNumberInput): PhoneNumber

Provision one of the numbers from a previous search.

The SDK generates the key pair that seals the number's messages, registers the public key with the service, and keeps the private key in the device key store. Losing that private key makes the number's messages unreadable.

The returned number is in com.sudoplatform.sudotelephony.types.PhoneNumberState.PROVISIONING; the order completes asynchronously with the telephony provider.

Return

The PhoneNumber being provisioned.

Parameters

input

ProvisionPhoneNumberInput The search and number to provision.

Throws

SudoTelephonyClient.PhoneNumberException

if the number could not be provisioned.
