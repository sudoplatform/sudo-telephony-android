searchAvailablePhoneNumbers

abstract suspend fun searchAvailablePhoneNumbers(input: SearchAvailablePhoneNumbersInput): PhoneNumberSearch

Search for phone numbers available to provision in an area code.

The service keeps the returned search for a short time so that provisioning can check the requested number came from it. The carrier does not reserve the numbers, so one can be taken by someone else before it is provisioned.

Return

The PhoneNumberSearch holding the available numbers.

Parameters

input

SearchAvailablePhoneNumbersInput Parameters narrowing the search.

Throws

SudoTelephonyClient.PhoneNumberSearchException

if the search could not be completed.
