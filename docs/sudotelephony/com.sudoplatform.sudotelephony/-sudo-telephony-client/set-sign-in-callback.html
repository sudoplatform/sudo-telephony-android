setSignInCallback

abstract fun setSignInCallback(callback: SudoPlatformSignInCallback?)

Set a callback that signs the user in when an operation is attempted while they are signed out.

When a callback is set, every operation that calls the service first checks whether the user is signed in and, if not, invokes the callback before continuing. If the callback throws, the exception is propagated to the caller and the operation is not executed. Subscriptions, key import and export, reset and close are not checked.

The client holds the callback through a weak reference, so the caller must keep its own reference for as long as the callback should stay in effect.

Parameters

callback

SudoPlatformSignInCallback The callback to invoke, or null to stop checking, which is the default.
