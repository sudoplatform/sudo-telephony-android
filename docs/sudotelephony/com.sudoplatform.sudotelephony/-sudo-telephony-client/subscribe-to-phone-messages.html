subscribeToPhoneMessages

abstract suspend fun subscribeToPhoneMessages(subscriptionId: String, subscriber: PhoneMessageSubscriber)

Subscribe to the caller's phone messages being received, updated or deleted.

An event carries no message content; fetch the message with getPhoneMessage to read its text.

Subscribing again with the same subscriptionId replaces the previous subscriber.

Parameters

subscriptionId

String A unique identifier for this subscription.

subscriber

PhoneMessageSubscriber Notified when one of the caller's messages changes.

Throws

SudoTelephonyClient.PhoneMessageException

if the subscription could not be established.
